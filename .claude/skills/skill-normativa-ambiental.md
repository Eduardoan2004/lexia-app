# Skill: Normativa Ambiental Argentina — Análisis y Cumplimiento

## Propósito

Guía al modelo para analizar normativa ambiental (leyes, resoluciones, disposiciones) aplicable a empresas clientes de EANDRES SIL, produciendo briefings de cumplimiento con checklist operativo, plazos administrativos y estrategia ante organismos de control.

---

## Cuándo aplicar este skill

- El input es una norma ambiental nacional, provincial (PBA) o de la CABA
- Se analiza el estado de habilitación ambiental de un cliente (CAA, EIA, RAA)
- Se requiere respuesta ante intimación de APrA, OPDS o ACUMAR
- Se evalúa impacto de nueva norma sobre actividad industrial, sanitaria o comercial
- Se prepara documentación para renovación/obtención de Certificado de Aptitud Ambiental

## Marco normativo de referencia

### Nacional
- **Ley 25.675** — Ley General del Ambiente (LGA): principios preventivo, precautorio, responsabilidad, acceso a información
- **Ley 25.612** — Gestión de residuos industriales y de actividades de servicio
- **Ley 25.670** — PCBs (transformadores, capacitores)
- **Ley 24.051** — Residuos peligrosos (decreto reglamentario 831/93)
- **Ley 25.916** — Residuos sólidos urbanos
- **Ley 26.562** — Quema de vegetación
- **Ley 27.279** — Gestión de envases de fitosanitarios

### CABA — APrA (ex APRA)
- **Ley 123 (CABA)** — Evaluación de Impacto Ambiental: categorías Sin Relevante Efecto (SRE), Con Relevante Efecto (CRE), Con Relevante Efecto Especial (CREE)
- **Ley 1356 (CABA)** — Calidad atmosférica
- **Ley 1854 (CABA)** — Basura cero / residuos sólidos urbanos
- **Decreto 222/12 (CABA)** — Reglamentación Ley 123, rubros y categorías
- **Disposiciones APrA** — actualización de rubros, guías sectoriales

### Provincia de Buenos Aires — OPDS
- **Ley 11.723 (PBA)** — Ley ambiental provincial
- **Ley 11.459 (PBA)** — Radicación industrial: categorías 1ª, 2ª, 3ª
- **Decreto 1741/96 (PBA)** — Reglamentación Ley 11.459
- **Ley 11.720 (PBA)** — Residuos especiales
- **Resoluciones OPDS** — límites de vuelco, emisiones, ruido

### ACUMAR — Cuenca Matanza-Riachuelo
- **Ley 26.168** — creación ACUMAR
- **Resoluciones ACUMAR** — Plan de Reconversión Industrial (PRI), Agentes de Contaminación Relevante (ACR)
- **Causa Mendoza** (CSJN) — marco de cumplimiento obligatorio

## Estructura del análisis

### 1. Identificación de la norma
```
Tipo: [Ley / Decreto / Resolución / Disposición]
Número y jurisdicción:
Fecha B.O.:
Vigencia / entrada en vigor:
Organismo emisor:
Actividades/sectores alcanzados:
```

### 2. Síntesis ejecutiva (3-5 líneas)
Qué cambia, para quién, desde cuándo. Foco en el impacto operativo sobre el cliente.

### 3. Impacto por área

| Área | Impacto | Urgencia |
|------|---------|----------|
| Habilitación / CAA | | Alta / Media / Baja |
| Residuos (industriales / patogénicos / especiales) | | |
| Emisiones / efluentes / ruido | | |
| Seguridad e higiene laboral | | |
| Responsabilidad civil / penal ambiental | | |

### 4. Checklist de cumplimiento

- [ ] **[Acción concreta]** — plazo: [DD/MM/AAAA] — responsable: [Estudio / RRHH / Dirección / Consultor ambiental]
- [ ] ...

Priorizar por urgencia y consecuencia (clausura > multa > intimación). Máximo 10 ítems.

### 5. Estrategia ante organismo de control

Indicar según el caso:
- **Presentación espontánea** vs. esperar intimación
- **Documentación mínima requerida** para regularización
- **Plazos de gracia** o regímenes de adhesión vigentes
- **Antecedentes** de la empresa ante el organismo (si conocidos)

### 6. Riesgos y alertas

- Clausura preventiva (APrA/OPDS tienen facultad)
- Responsabilidad personal de directores (Art. 59 LSC + LGA)
- Daño ambiental colectivo (Art. 28 Ley 25.675) — acción popular
- Conexión con causa penal ambiental (Art. 55 Ley 24.051 — residuos peligrosos)
- ACUMAR: incumplimiento PRI → sanciones + publicidad adversa (*Causa Mendoza*)

### 7. Clientes a notificar

Igual que skill laboral — indicar cliente, motivo y canal.

## Reglas de calidad

1. **Perspectiva empresarial** — minimizar exposición, maximizar cumplimiento con el menor costo operativo
2. **Jurisdicción explícita** — CABA y PBA tienen regímenes distintos; nunca mezclar sin aclarar
3. **CAA siempre presente** — toda empresa necesita CAA vigente; si no se menciona, preguntar estado
4. **Sin citas inventadas** — si no se tiene número de resolución, indicar "verificar en BO/APrA"
5. **Plazo fatal destacado** — si hay plazo de clausura o sanción, resaltarlo en el checklist
6. **Residuos patogénicos** — Franchin tiene régimen especial GCBA Salud + APrA; no asimilar a residuos industriales comunes
7. **Branding EANDRES SIL** — Navy #0F2244, Gold #C9A84C, Cyan #00B4D8, tipografía Inter

## Patrones de prompt para Gemini (Módulo Normativa)

### Prompt base — análisis general ambiental
```
Sos un especialista en derecho ambiental argentino con experiencia en cumplimiento empresarial.
Analizá la siguiente norma ambiental y producí un briefing ejecutivo con:
síntesis, impacto operativo por área, checklist de cumplimiento con plazos,
riesgos de incumplimiento y estrategia ante el organismo de control.
Norma: {texto_o_numero}
Cliente: {cliente_nombre} — Actividad: {actividad} — Jurisdicción: {caba/pba/nacional}
```

### Prompt — estado CAA
```
Evaluá el estado de cumplimiento ambiental de una empresa de {actividad}
en jurisdicción {caba/pba} respecto al Certificado de Aptitud Ambiental.
Identificá: (1) categoría Ley 123 / Ley 11.459 aplicable, (2) documentación requerida,
(3) plazos de renovación, (4) consecuencias de CAA vencido o inexistente.
```

### Prompt — respuesta a intimación
```
La empresa {cliente} recibió una intimación de {organismo} por {motivo}.
Elaborá una estrategia de respuesta que incluya: (1) análisis de la intimación,
(2) documentación a presentar, (3) plazo de respuesta, (4) argumentos de defensa,
(5) riesgo de clausura y medidas preventivas.
```

### Prompt — residuos patogénicos (Franchin)
```
Analizá el régimen de gestión de residuos patogénicos aplicable a un sanatorio
en CABA bajo Ley 154/99 CABA y normativa APrA vigente. Identificá: operadores
habilitados, manifiestos requeridos, periodicidad de retiro, y consecuencias
del incumplimiento ante APrA y GCBA Ministerio de Salud.
```
